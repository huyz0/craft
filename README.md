# Craft

Craft is an agent-facing cloud CLI for the AI software factory, implemented in Rust under [`cli/`](cli/README.md). The development binary supports local discovery and input/schema validation. Cloud clients and live integrations are still being built.

- [CLI project, applied SDD workflow and detailed tasks](cli/README.md)
- [Project coding/comment standard](cli/docs/coding-standard.md)
- [Software-factory and CLI research](docs/researches/README.md)
- [Factory launcher and local verification](factory/README.md)

The selected executable name is `craft`. Planning identifiers stay in planning records; code and comments use semantic behavior/design descriptions.
