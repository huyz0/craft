# Typed recovery candidates and persisted authority

Date: **10 November 2026**, Australia/Sydney. Internal implementation only. Baseline: [journal-bound Jira reconciliation](jira-reconciliation.md). No live tenant, real credential provisioning, public cloud registration, publication or deployment was changed.

## Implemented behavior

The [recovery contract](../jira-reconciliation.md), operation-recovery scenarios and design were updated before implementation. `crates/craft-runtime/src/issue_recovery_policy.rs` persists a separate per-project recovery record with installation/profile/grant/project/actor binding and six explicit original-command allowances. Trusted updates require apply, receipt preflight and revision CAS. Actor transfer requires disabling the old identity first. Read/create/mutation policies grant no recovery permission, and recovery grants no write permission. SQLite schema nine creates an empty table atomically; existing payload formats remain unchanged.

`crates/craft-cli/src/issue_recovery/command.rs` adds strict flags/JSON candidates, exact original canonical input, normal profile/site resolution and captured policy verification. Required original input rejects missing/null values. Local validation and minimum recovery output preflight precede state access. Original target and selection are not reconstructed or rewritten. Complete dispatch retains evidence and warnings. The parser variant is skipped and registration is internal, so public discovery does not expose this capability.

The host now separates journal binding/full output preflight from credential construction. Missing records and unknown creates without read identities return locally without opening the credential backend. Credential-opening/locking failures retain captured journal evidence. Existing cached execution uses the same sealed read plan and rechecks the complete persisted policy before access, at native boundaries and after final clock work. Auth rate advice is retained. No journal marker is reset and no original write is replayed.
