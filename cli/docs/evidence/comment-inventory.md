# Complete native comment inventory

Date: 10 November 2026. Implemented `craft-cli::confluence_reads::inventory` as the native observation component needed by the review verifier. No public command, tenant mutation, schema migration, dependency or credential-format change is introduced. Public command availability remains 41.

`PreparedInventory` loads an explicitly named Confluence Cloud service profile and captures its native read policy. Both root and reply allowances must exist before authentication. One sealed access acquisition supplies actual actor/grant/tenant/scope proof. Captured configuration and freshness are rechecked at native boundaries and after the final clock checks. A result preserves credential-cache effects independently from the all-or-error inventory. Neither result nor preparation has an evidence-JSON deserializer.

Traversal exhausts root pages before breadth-first traversal of every observed comment's direct replies, including leaves. Global IDs reject duplicate/cyclic membership; each collection tracks continuation history. Current page/parent association, selected storage body, metadata and fingerprint must agree. Limits are 1,024 comments, 65,536 encoded bytes per body, 8 MiB encoded bodies, 2,048 native collection pages and a successful observation interval below 30 seconds on both clocks. Backward clocks and cancellation refuse success. The caller's deadline bounds I/O; late responses cannot become a complete result. Exhaustion is an observation, not an atomic snapshot or approval.
